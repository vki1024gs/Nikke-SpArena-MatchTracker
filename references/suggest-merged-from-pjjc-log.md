# suggest — 队伍机制核查

## Purpose
核查**脚本输出的爆裂链成员**（开启爆裂的人）是否包含特定"mechanics"。

## Rules
1. **严格依赖脚本**：分析对象必须是 `burst_chain_speed.py` 输出的"爆裂链"中的那 3 个人。
2. **数据来源**：直接读取 `references/characters_pvp.toml` 中的 `mechanics` 字段。
   - 格式为 `["机制：解释"]`。输出时需包含解释。
   - 若仅为名称（如 `["不屈"]`），则只输出名称。
3. **报喜不报忧**：**只列出存在的机制**。若某角色无机制，或无相关机制，直接跳过，不要说"无"。
4. **输出格式**：自然陈述的一段话。禁止使用“信号核查”、“分析如下”等前缀。

## Workflow
1. 解析脚本输出，锁定 3 个角色。
2. 读取对应角色的 `mechanics` 字段。
3. 组装输出。
   - 例：“队伍在爆裂期间拥有无敌（诺雅：全队无敌）。”
   - 若无机制，则不输出。
